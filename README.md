# 📈 Анализ эффективности рекламных каналов

## О проекте

Практический кейс по анализу эффективности рекламных каналов.

Цель проекта — сравнить результаты рекламных каналов, проанализировать расходы и определить наиболее и наименее эффективные источники привлечения пользователей.

## Задача

В рамках кейса необходимо было:

- проанализировать показатели рекламных каналов;
- сравнить эффективность каналов между собой;
- проанализировать расходы;
- определить наиболее эффективный канал;
- определить канал с наименее эффективными результатами;
- сформулировать выводы по результатам анализа.

## Инструменты

- Microsoft Excel
- Анализ данных
- Расчёт показателей эффективности
- Визуализация данных

## Результаты

По результатам анализа:

- **TG** показал наиболее высокую эффективность среди рассматриваемых каналов;
- **РСЯ** оказался наименее эффективным каналом;
- Трафик лучше направить на страницу `/computers`.
- ROMI рассчитать нельзя т.к. не хватает данных (доходов)

## Выводы

Результаты анализа позволяют сделать вывод о различиях в эффективности рекламных каналов и использовать полученные данные для принятия решений о дальнейшем распределении рекламного бюджета.
